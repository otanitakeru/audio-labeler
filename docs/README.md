# audio-labeler 操作ドキュメント

audio-labeler の操作方法・設定・ショートカットキーをまとめた仕様書です。
人が操作を調べるときと、AI がアプリの挙動を把握するときの両方で読むことを想定しています。

- 起動方法とアプリの概要は、リポジトリ直下の [README.md](../README.md) を見てください
- 「なぜその仕様にしたか」(設計の理由・実装方針)は [PLAN.md](../PLAN.md) にあります。このフォルダには **何ができて、どう操作するか** だけを書きます

## 表記のルール

- キーは Mac の表記で書きます。Windows 等では <kbd>⌘</kbd> を <kbd>Ctrl</kbd>、<kbd>⌥</kbd>(Option)を <kbd>Alt</kbd> に読み替えてください。OS で既定値が変わるもの(やり直すなど)は両方書きます
- 画面上の文言(ボタン・メニュー・項目名)は「」で囲み、画面の表示どおりに書きます
- 既定値は、設定を一度も変えていないときの値です

## ドキュメントの更新について

アプリの操作・設定・ショートカット・ファイル形式を変えたときは、同じ変更でこのフォルダも更新します(ルールは [CLAUDE.md](../CLAUDE.md) に書いています)。

## 画像の撮り直し

画像(`images/`)は、[screenshots/capture.mjs](screenshots/capture.mjs) で実際の画面を撮ったものです。見た目が変わったときは撮り直してください。

### 撮る条件

スクリプトが次の状態を作ってから撮ります。

- 保存済みの設定を消し、既定値に戻す。ただし波形の高さは 260px(画像に収まるよう、既定の 600px から縮める)
- ウィンドウの幅は 1280px
- 音声を「自動検出まで」で読み込み、先頭の3区間にラベル(「おはようございます」など)を入れて、2つ目の区間を選んだ状態

これまでの画像は `mock-data/mock_wav.wav`(48 kHz・24 bit・2 ch、約57秒)で撮っています。`mock-data/` はリポジトリに含めていないため、手元にないときは別の wav を指定してください(区間の位置などは今の画像と変わります)。2ch 以上の wav にすると、チャンネルの欄も写ります。

### 手順

1. アプリを起動する(`./start.sh`)。スクリプトは http://localhost:5173 を操作します
2. 初回だけ、スクリプトの依存をインストールする

   ```bash
   cd docs/screenshots && npm install
   ```

3. 撮る(`docs/images/` の画像を上書きします)

   ```bash
   cd docs/screenshots && npm run capture
   ```

   別の wav を使うときは、パスを渡します。

   ```bash
   cd docs/screenshots && npm run capture -- /path/to/audio.wav
   ```

4. `git diff` で画像の変化を見て、意図しない変化(ダイアログが閉じていない、表示が崩れているなど)がないか確かめる

- Chrome は Mac の標準の場所(`/Applications/Google Chrome.app`)のものを使います。別の場所にあるときは `CHROME_PATH` で指定します。アプリの URL を変えるときは `APP_URL` で指定します
- ブラウザは別のプロファイルで開くため、普段使っているブラウザの設定は変わりません

### 画像を足す・変えるとき

- 新しい画像は `capture.mjs` に撮る処理を足し、スクリプトから撮れるようにします(手で撮った画像を混ぜると、次に撮り直すときに漏れるため)
- [screen.md](screen.md) の番号付きの図(`screen-layout.png`)は、表の番号と `capture.mjs` の枠の番号を対応させています。画面の構成を変えたときは両方を直します
- 画面の部品の場所は、ボタンの文言や Tailwind のクラス名(波形の枠)で探しています。文言や構成を変えて撮れなくなったときは、`capture.mjs` の探し方も直します
