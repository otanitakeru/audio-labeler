# キーボードショートカット

Mac の表記です。Windows 等では <kbd>⌘</kbd> を <kbd>Ctrl</kbd>、<kbd>⌥</kbd>(Option)を <kbd>Alt</kbd> に読み替えてください。

すべて [設定 > ショートカットキー](settings.md#ショートカットキー) で割り当てを変えられます。下の表は初期値です。

## 一覧

設定ダイアログと同じまとまりで並べています。

### 基本操作

| 操作            | 初期値           | 補足                                                       |
| --------------- | ---------------- | ---------------------------------------------------------- |
| 再生 / 一時停止 | <kbd>Space</kbd> | 選択範囲・選択中の区間があれば、その先頭から末尾までを再生 |

### ラベル

| 操作                     | 初期値                                                                                            | 補足                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 選択範囲にラベルを追加   | <kbd>⌘</kbd> + <kbd>B</kbd>                                                                       | 入力して <kbd>Enter</kbd> で確定、<kbd>Esc</kbd> で取り消し                |
| 選択中の区間を削除       | <kbd>Backspace</kbd>                                                                              | Mac の delete キー                                                         |
| 区間の選択を解除         | <kbd>Esc</kbd>                                                                                    |                                                                            |
| 前の区間を選択           | <kbd>←</kbd>                                                                                      |                                                                            |
| 次の区間を選択           | <kbd>→</kbd>                                                                                      |                                                                            |
| 選択中の区間の文言を編集 | <kbd>Enter</kbd>                                                                                  | 編集中の <kbd>Enter</kbd> は確定。続けて押すと編集の開始・確定が切り替わる |
| 元に戻す                 | <kbd>⌘</kbd> + <kbd>Z</kbd>                                                                       |                                                                            |
| やり直す                 | Mac: <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd><br>Windows 等: <kbd>Ctrl</kbd> + <kbd>Y</kbd> | OS の慣習に合わせて初期値が違う                                            |

### 区間の調整

| 操作                       | 初期値                                         |
| -------------------------- | ---------------------------------------------- |
| 前の区間と結合             | <kbd>⌥</kbd> + <kbd>←</kbd>                    |
| 次の区間と結合             | <kbd>⌥</kbd> + <kbd>→</kbd>                    |
| 開始を左へずらす           | <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>←</kbd> |
| 開始を右へずらす           | <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>→</kbd> |
| 終了を左へずらす           | <kbd>⌘</kbd> + <kbd>←</kbd>                    |
| 終了を右へずらす           | <kbd>⌘</kbd> + <kbd>→</kbd>                    |
| 選択中の区間を自動検出     | <kbd>⌘</kbd> + <kbd>D</kbd>                    |
| プリセットを選んで自動検出 | <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> |

### マウスとの組み合わせ(割り当ては変えられない)

| 操作                                       | 結果                      |
| ------------------------------------------ | ------------------------- |
| メイン波形の上で <kbd>⌘</kbd> + ホイール   | 横方向に拡大 / 縮小       |
| 振幅の目盛りの上で <kbd>⌘</kbd> + ホイール | 縦方向(振幅)に拡大 / 縮小 |

## 各操作の細かい挙動

### 前 / 次の区間を選択

- 開始時刻の順で隣の区間を選びます。何も選んでいなければ、再生位置の前 / 後の区間を選びます
- 選ぶと同時に再生を止め、再生位置を区間の先頭に置きます。続けて <kbd>Space</kbd> でその区間を聞けます
- 区間が表示範囲の外なら、表示位置も動きます
- 選択範囲は解除されます

### 前 / 次の区間と結合

- 選択中の区間と隣の区間を、間の無音も含めて1つにします
- ラベルは時間の順に半角スペースでつなぎます(空のラベルは飛ばします)
- 結合した後も選択は残ります

### 開始 / 終了をずらす

- 1回あたりの移動量は [設定 > 編集](settings.md#編集) の「境界をずらす量」です(既定 10ms)
- 押し続けると、押している時間に応じて1回あたりの移動量が設定値の 2倍・5倍・10倍と段階的に増えます。ただし1回あたり 100ms までです(設定値が 100ms 以上なら加速しません)
- 他の区間と重なる場合はエラーになります
- 押し続けた分は、元に戻す1回でまとめて戻ります

### 選択中の区間を自動検出

- 選択中の区間の中だけを、「選んだ区間」で前回使ったプリセットで検出し直します。ダイアログは出ません
- 区間にラベルがあるときは、置き換える前に確認が出ます
- プリセットを変えたいときは「プリセットを選んで自動検出」を使います。「自動検出」ボタンを押したときと同じダイアログが、対象「選んだ区間」で開きます

## ショートカットが効かないとき

- ラベルの入力中・ダイアログの表示中は、ショートカットは効きません(ブラウザ本来の動作になります)
- 自動検出・文字起こしの実行中は、ショートカットは何もしません

## ブラウザのショートカットとの関係

次のキーはブラウザにも割り当てがありますが、このアプリでは選択中の区間がなくてもブラウザの動作に渡しません(編集画面から離れたり、ブックマークのダイアログが出たりしないようにするため)。

| キー                                            | ブラウザでの割り当て             |
| ----------------------------------------------- | -------------------------------- |
| <kbd>⌘</kbd> + <kbd>←</kbd> / <kbd>→</kbd>(Mac) | 戻る / 進む                      |
| <kbd>Alt</kbd> + <kbd>←</kbd>(Windows)          | 戻る                             |
| <kbd>⌘</kbd> + <kbd>D</kbd>                     | ブックマークに追加               |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd>  | すべてのタブをブックマークに追加 |

## 割り当てを変えるとき

- 設定ダイアログの「ショートカットキー」で、変えたい操作のキーのボタンを押すと「キーを入力...」になるので、割り当てたいキーを押します。やめるときは、もう一度ボタンを押すか、ほかの場所を押します
- 他の操作と同じキーは割り当てられません(「このキーは既に他の操作に割り当てられています」と出ます)
- 初期値から変えた操作には「デフォルトに戻す」が出ます
- 割り当ては OK を押したときに反映され、ブラウザに保存されます。初期値から変えたものだけを保存するので、アプリ側で初期値が変わったときは、変えていない操作にはそれが反映されます
