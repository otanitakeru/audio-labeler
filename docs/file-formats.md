# ファイル形式

## 音声ファイル

- `.wav` のみ対応しています
- チャンネル数は任意です。読み込むときに選んだ1チャンネルだけを使います(平均してモノラルにはしません)

## ラベルファイル

「ファイル」→「ラベルを書き出す」で保存し、読み込みのダイアログの「ラベル」や「ファイル」→「ラベルを読み込む」で読み込むファイルです。

1行に1区間、タブ区切りで `開始秒 終了秒 ラベル` を書きます。

```text
0.52	1.84	おはようございます
2.1	3.675	今日は晴れです
```

タブを `\t` で書くと、次のようになります。3行目はラベルが空の区間です。

```text
0.52\t1.84\tおはようございます
2.1\t3.675\t今日は晴れです
5.03\t5.6\t
```

| 項目       | 内容                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 区切り     | タブ(`\t`)。ラベルに半角スペースを含めてもエスケープは不要                                       |
| 列数       | 必ず3列。ラベルが空の区間も、終了秒の後ろにタブを書く(上の例の3行目)                             |
| 秒数       | 桁数は固定しない。小数点以下3桁などに切り詰めず、そのまま書く(JavaScript の数値を文字列にした形) |
| ラベル     | 空でもよい。タブ・改行は入力時に半角スペースへ置き換わるため、ファイルに入ることはない           |
| 並び順     | 書き出すときは開始時刻の順。読み込むときは順不同でよい                                           |
| 空行       | 読み込むときは無視する。改行コードは LF / CRLF のどちらでもよい                                  |
| 文字コード | UTF-8                                                                                            |
| ファイル名 | 書き出すときは `<音声のファイル名>.txt`。読み込みは `.txt` / `.tsv` を選べる                     |

読み込むときは、次のどれかに当てはまるとエラーになり、読み込みません。

- 形式の誤り(タブ区切りで3列になっていない、秒数が数値でない など。何行目かがエラーに出る)
- 区間同士の重なり
- 音声の長さを超える区間(1ms までのはみ出しは許す)

## 音声の切り出し(ZIP)

「ファイル」→「音声を切り出す」で保存するファイルです。

```text
<元ファイル名>_segments.zip
└── <元ファイル名>/
    ├── wav/
    │   ├── 0001.wav
    │   ├── 0002.wav
    │   └── ...
    ├── segment.txt   # id 開始秒 終了秒
    └── text.txt      # id ラベル(「ラベルも保存」がオンのときだけ)
```

### id

- 書き出す区間を開始時刻の順に並べ、1 から振った連番です。wav のファイル名(拡張子を除く)と同じです
- 「ゼロ埋めする」がオンのときは、件数の桁数にそろえます(10〜99件なら `01`、100〜999件なら `001`)。9件以下ならゼロ埋めしないときと同じです

### segment.txt / text.txt

```text
# segment.txt
0001	0.52	1.84
0002	2.1	3.675

# text.txt
0001	おはようございます
0002	今日は晴れです
0003
```

- 区切りはダイアログで「タブ区切り」(既定)か「スペース区切り」を選べます。両方のファイルに当てはまります
  - スペース区切りにすると、Kaldi の `segments` / `text` の形式としてそのまま使えます。ラベル中の半角スペースはエスケープしません(最初の区切りで id と分ければ読めるため)
- ラベルが空の区間も、text.txt には id だけの行として入れます(行数を segment.txt とそろえるため)。行末に区切りは付けません
- 秒数の書き方はラベルファイルと同じです

### wav

- 区間どおりに切ります(前後の余白は足しません)。境界は元ファイルのサンプリング周波数で最も近いサンプルに丸めます
- 波形表示用に変換した音声ではなく、元ファイルから切り出します
- チャンネル・サンプリング周波数・ビット深度はダイアログで選んだとおりに変換します([操作方法 > 音声を切り出す](usage.md#音声を切り出す))
